# プライバシー

ModeDock は何も送信せずに動作します。同意した場合のみ、使った機能の匿名の回数を送信します。改善すべき点を知るために使います。

## 同意するまでオフ

初回起動時に ModeDock は「*匿名の使用状況データを共有しますか？*」と尋ねます。「共有」を選ばない限り、何も送信されません。この設定は 設定 → 一般 でいつでも変更できます。

## 送信される内容

約 8 時間ごとに、何かが記録された場合にのみ送信します：

- パネルを開いた、輝度を変えたなど、各機能を使った回数。回数だけで、画面の内容は送信しません。
- プロファイルや外部ディスプレイの数など、ModeDock の設定状況。名前は送信しません。
- アプリと macOS のバージョン、アプリの言語、Mac が Apple シリコンか Intel か。
- ランダムなインストール ID。共有をオンにしたときに作成され、オフにすると削除されます。あなた自身や Mac、Apple アカウントとは結び付いていません。

送信されるレポートをそのまま確認するには、設定 → 一般 の「データを表示…」を使います。

## サーバーが追加する情報

レポートが届いた日付と国。国はサーバーを運用する Cloudflare が判定します。サーバーは IP アドレスを読み取ったり保存したりせず、ログもオフにしています。

## 決して収集しないもの

- 名前、メールアドレス、Apple アカウント、入力した内容
- IP アドレス、シリアル番号、その他のハードウェア ID
- ディスプレイ、プロファイル、ファイルの名前、およびファイルの内容
- スクリーンショットや画面に表示されている内容

## 保管場所

欧州連合内の Cloudflare データベースに、`telemetry.modedock.app` を通じて保管されます。読み取れるのは ModeDock のメンテナーだけです。

## 公開される情報

ホームページには過去 30 日間の合計を表示します：アクティブなインストール数、よく使われる機能、macOS のバージョン、国。各数値は 5 インストール以上をまとめたもので、個人を特定することはできません。インストール ID や個々のレポートが公開されることはありません。

## オフにするには

設定 → 一般 の「匿名の使用状況統計を共有」のチェックを外します。ModeDock は送信を止め、インストール ID と記録した回数を削除します。再びオンにすると、新しいインストール ID が作成されます。

すでに送信したレポートを削除したい場合は、共有をオフにする前に、「データを表示…」に表示されるインストール ID を添えて [GitHub](https://github.com/ilijamt/modedock/issues) で issue を作成してください。
